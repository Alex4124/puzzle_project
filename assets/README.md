# Assets

Поместите сюда ваши игровые ассеты.

## Структура

```
assets/
├── images/          # Все изображения
│   ├── logo.png
│   ├── start_button.png
│   ├── background.jpg
│   └── ...
└── sounds/          # Все звуки
    ├── click.mp3
    ├── success.mp3
    └── ...
```

## Рекомендации

### Изображения
- Формат: PNG (для прозрачности) или WebP (для оптимизации)
- Размер: оптимизируйте перед добавлением
- Разрешение: 1080x1920 для вертикальной ориентации

### Звуки
- Формат: MP3 (лучшая совместимость)
- Битрейт: 128kbps
- Длительность: короткие эффекты (1-2 сек)

## После добавления ассетов

1. Зарегистрируйте их в `src/models/GameConfig.ts`
2. Добавьте в загрузчик в `src/GameApplication.ts`
3. Используйте через `AssetManager.getInstance().getAsset()`
