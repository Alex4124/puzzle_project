## 🚀 Как запустить:

1. **Установите зависимости:**
   ```bash
   cd magic-jigsaw-playable
   npm install
   ```

2. **Запустите dev-сервер:**
   ```bash
   npm run dev
   ```
   Откроется браузер на http://localhost:3000

3. **Соберите финальный HTML:**
   ```bash
   npm run build
   ```
   Результат в папке `dist/index.html` (один файл со всеми ассетами)

## 📝 Как добавить свои изображения:

### Вариант 1: Используйте текущие placeholder'ы
Сейчас работает с программно созданными элементами. Можете сразу протестировать!

### Вариант 2: Добавьте свои изображения

1. **Поместите файлы в папку assets:**
   - `assets/images/logo.png` - логотип (из вашего скриншота)
   - `assets/images/start_button.png` - кнопка Start
   - `assets/images/background.jpg` - фон (если нужен)

2. **Откройте `src/models/GameConfig.ts`** и раскомментируйте/добавьте:
   ```typescript
   public static readonly ASSET_LOGO = 'logo';
   public static readonly ASSET_START_BUTTON = 'start_button';
   ```

3. **Откройте `src/GameApplication.ts`**, найдите метод `loadAssets()` и раскомментируйте:
   ```typescript
   const assetsList: AssetConfig[] = [
     { name: GameConfig.ASSET_LOGO, path: '/assets/images/logo.png' },
     { name: GameConfig.ASSET_START_BUTTON, path: '/assets/images/start_button.png' },
   ];
   ```

4. **Перезапустите dev-сервер** - изображения загрузятся автоматически!

├── utils/

## 🔧 Особенности:

1. **Адаптивность:**
   - Автоматически подстраивается под размер экрана
   - Работает на мобильных и десктопах
   - Поддержка portrait/landscape ориентации

2. **Производительность:**
   - PixiJS использует WebGL
   - Оптимизированный рендеринг
   - Плавные анимации через GSAP

3. **Финальная сборка:**
   - Все ассеты встроены в HTML (base64)
   - Один файл без зависимостей
   - Размер: ~200-300 KB без изображений
